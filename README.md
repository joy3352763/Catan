# 森友拓荒島｜Cozy Catan

以 Three.js + TypeScript + Vite 製作的療癒系 3D 六角島嶼桌遊 MVP。使用原創低多邊形地形與動物島民 UI，不包含《動物森友會》的原作角色或美術素材。

## 開發環境

- Node.js 20.19+ 或 22.12+
- npm
- 可執行 WebGL 的現代瀏覽器

## 啟動

```bash
npm install
npm run dev
```

開啟 Vite 顯示的本機網址（通常是 `http://localhost:5173`）。正式建置：

```bash
npm run build
npm run preview
```

推送到 `main` 分支後，GitHub Actions（`.github/workflows/deploy.yml`）會自動建置並部署到 GitHub Pages。

## 操作方式

1. 初始配置階段，點選空的交叉點放村莊，再點選與它相連的道路邊。系統會自動處理順向與反向的放置順序，AI 會自動操作。
2. 進入你的回合後按「擲骰子」。非 7 點時，所有玩家依數字板塊領取資源；7 點時，手牌超過 7 張的玩家棄掉一半，然後點選另一塊地形移動盜賊。
3. 選擇「修築道路／建造村莊／升級城市」，地圖上會以**半透明閃爍的灰色虛影**標出所有合法位置（升級城市為金色虛影），再點選其中一個位置完成建造。
4. 可使用「銀行交易」交換資源（預設 4:1，擁有港口時可享 3:1 或 2:1 優惠）；滑動「結束回合」讓 AI 行動。
5. 最先達到 10 分的玩家獲勝。

## 規則：港口（規劃中）

### 港口種類與數量

地圖外圍共設置 **9 座港口**，比照標準版配置：

| 港口 | 數量 | 優惠 |
| --- | --- | --- |
| 通用港 ⚓ | 4 | 任一種資源 **3:1** 換 1 張任意資源 |
| 木材港 🪵 | 1 | 木材 **2:1** |
| 磚頭港 🧱 | 1 | 磚頭 **2:1** |
| 小麥港 🌾 | 1 | 小麥 **2:1** |
| 羊毛港 🐑 | 1 | 羊毛 **2:1** |
| 鐵礦港 ⛰️ | 1 | 鐵礦 **2:1** |

### 港口設置

- 港口位於島嶼外圍的**海岸邊**上，每座港口佔據該邊的 **2 個交叉點**（以棧橋連接到海岸）。
- 外圍海岸共有 30 條邊，9 座港口沿海岸線**大致平均分布**（約每 3～4 條邊一座），且兩座港口的交叉點不可相鄰或重疊。
- 港口種類在開新局時**隨機洗牌**後分配到這 9 個位置，與地形一樣每局不同。
- 3D 場景中以海面上的小木棧橋 + 浮標/旗幟表示，旗幟顯示資源圖示與比例（如「🐑 2:1」「⚓ 3:1」）。

### 港口優惠的取得與使用

- 玩家在港口的任一交叉點上擁有**村莊或城市**，即可使用該港口（初始配置放置的村莊也算）。
- 銀行交易時，每種資源自動套用該玩家**最優惠的比例**：專屬 2:1 港 > 通用 3:1 港 > 預設 4:1。
- 交易視窗會顯示目前可用比例，資源不足以支付該比例時無法交易。
- AI 玩家同樣會利用自己擁有的港口優惠進行交易。

## 規則：船隻（規劃中，參考航海家擴充）

### 地圖調整

- 在主島 19 格外圍加上一圈**海洋格**（18 格），船隻只能航行於海上。
- 海洋格上可額外散布 2～3 座**小離島**（1～2 格陸地，無港口），只能透過船隻抵達，作為開拓獎勵。

### 建造

- 費用：**1 木材 + 1 羊毛**。
- 每位玩家最多 **15 艘**船。
- 船隻放置在**至少一側鄰接海洋格**的邊上（海岸邊或兩海洋格之間的邊）。
- 船隻必須連接到自己的**村莊／城市**，或連接到自己的另一艘船。

### 道路與船隻的連接

- 道路只能接道路，船隻只能接船隻；**兩者只能透過村莊或城市互相銜接**（在海岸村莊一側接道路、另一側接船隻）。
- 可在船隻航線末端的空交叉點建造村莊（需符合距離規則），藉此登陸離島。

### 移動船隻

- 每回合可**移動 1 艘船**一次，但只能移動「開放航線」末端的船（末端沒有連接自己的村莊／城市）。
- 本回合剛建造的船隻不可移動。
- 移動後的新位置同樣須符合建造規則，且必須與自己的航線或建築相連。

### 計分與其他

- 船隻與道路可共同計入**最長貿易路線**（道路與船隻需透過村莊／城市相連才可串接）。
- 首次在離島上建造村莊可額外獲得 **1 分**開拓獎勵（每座離島每位玩家限一次）。
- 海盜（盜賊的海上版本）暫不實作，擲出 7 點時仍只移動陸上盜賊。

## 專案結構

- `src/game.ts`：純 TypeScript 規則模型、六角板塊與道路圖、資源生產、建設合法性、盜賊、交易、AI 決策與勝負判定。
- `src/main.ts`：Three.js 場景、點擊選取、建造位置提示、UI 與遊戲狀態呈現。
- `src/style.css`：響應式療癒系介面（含手機直立 HUD 模式）。

## MVP 範圍與已知限制

目前可玩流程包含：19 格六角地圖、五種資源、4 位玩家（1 人 + 3 AI）、雙向初始配置、擲骰生產、7 點盜賊與棄牌、道路／村莊／城市、建造位置提示、4:1 銀行交易、10 分勝利條件。

**開發路線圖**

1. 港口：地圖港口生成 → 3D 棧橋與旗幟 → 交易比例計算 → 交易 UI 顯示比例 → AI 使用港口。
2. 船隻：外圍海洋格與離島 → 船隻建造與合法性 → 船隻移動 → 最長貿易路線 → AI 造船策略。

尚未實作：發展卡、騎士與最大軍隊、最長道路的 2 分獎勵、AI 玩家間交易、存檔與多人連線。地形／數字為隨機配置，尚未加入標準版的紅數字（6、8）相鄰限制。這是可執行的 MVP 起點，不宣稱等同完整官方規則。

# 森友拓荒島｜Cozy Catan

以 Three.js + TypeScript + Vite 製作的療癒系 3D 六角島嶼桌遊 MVP。使用原創低多邊形地形與動物島民 UI，不包含《動物森友會》的原作角色或美術素材。

## 開發環境

- Node.js 20.19+ 或 22.12+
- npm
- 可執行 WebGL 的現代瀏覽器

## 啟動

```bash
npm install
npm run dev
```

開啟 Vite 顯示的本機網址（通常是 `http://localhost:5173`）。正式建置：

```bash
npm run build
npm run preview
```

## 操作方式

1. 初始配置階段，點選空的交叉點放村莊，再點選與它相連的道路邊。系統會自動處理順向與反向的放置順序，AI 會自動操作。
2. 進入你的回合後按「擲骰子」。非 7 點時，所有玩家依數字板塊領取資源；7 點時，手牌超過 7 張的玩家棄掉一半，然後點選另一塊地形移動盜賊。
3. 選擇「修築道路／建造村莊／升級城市」，再點地圖上合法的位置。
4. 可使用「銀行交易」以 4:1 交換資源；按「結束回合」讓 AI 行動。
5. 最先達到 10 分的玩家獲勝。

## 專案結構

- `src/game.ts`：純 TypeScript 規則模型、六角板塊與道路圖、資源生產、建設合法性、盜賊、交易、AI 決策與勝負判定。
- `src/main.ts`：Three.js 場景、點擊選取、UI 與遊戲狀態呈現。
- `src/style.css`：響應式療癒系介面。

## MVP 範圍與已知限制

目前可玩流程包含：19 格六角地圖、五種資源、4 位玩家（1 人 + 3 AI）、雙向初始配置、擲骰生產、7 點盜賊與棄牌、道路／村莊／城市、4:1 銀行交易、10 分勝利條件。

為保持第一版範圍可控，尚未實作發展卡、騎士與最大軍隊、最長道路的 2 分獎勵、港口優惠、AI 玩家間交易、存檔與多人連線。地形／數字為隨機配置，尚未加入標準版的紅數字相鄰限制與港口配置。這是可執行的 MVP 起點，不宣稱等同完整官方規則。
